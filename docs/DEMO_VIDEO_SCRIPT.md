## 🎥 Production Notes

### Visual Style
- **Modern, clean, professional**
- **Purple/Blue gradient theme (matching IQ AI brand)**
- **Smooth transitions (fade, slide)**
- **Screen recordings in 1080p or 4K**
- **No jarring cuts - flow naturally**

### Audio
- **Professional voiceover (male or female, clear accent)**
- **Background music: Upbeat, tech-focused, not distracting**
- **Sound effects: Subtle whooshes for transitions, success pings**

### Pacing
- **Speak clearly but with energy**
- **Pause 1-2 seconds between major points**
- **Let visuals breathe - don't rush**
- **Build excitement toward the end**

### Text Overlays
- **Large, readable font (24-36pt)**
- **High contrast (white text on dark background)**
- **Appear with subtle fade-in**
- **Stay on screen 2-3 seconds minimum**

### Call-Outs
Use colored boxes/arrows to highlight:
- Buttons being clicked
- Important numbers/metrics
- Key UI elements
- Recommendation results

## ✅ Pre-Flight Checklist

### Before Recording
- [ ] All features working (test extensively)
- [ ] Demo data loaded and looks good
- [ ] No console errors in browser
- [ ] Clean browser window (no extra tabs/bookmarks)
- [ ] Screen resolution set to 1920x1080
- [ ] Notifications disabled
- [ ] Cursor/mouse pointer visible and highlighted

### During Recording
- [ ] Record in multiple takes (splice best parts)
- [ ] Capture UI at 60fps for smooth playback
- [ ] Use screen recording software (OBS, Camtasia)
- [ ] Record voiceover separately for better quality
- [ ] Capture backup footage (in case of issues)

### After Recording
- [ ] Edit for pacing and flow
- [ ] Add background music and sound effects
- [ ] Add text overlays and call-outs
- [ ] Color grade for consistency
- [ ] Export in 1080p MP4 (H.264)
- [ ] Upload to YouTube as unlisted
- [ ] Create thumbnail with logo + key metric
