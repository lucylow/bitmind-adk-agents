## 🚀 How to Run

```bash
# Install dependencies
npm install

# Configure environment
cp env.adk.example .env.local
# Add your GOOGLE_API_KEY or OPENAI_API_KEY

# Start ADK backend
npm run adk:run

# Start frontend (separate terminal)
npm run dev

# Visit http://localhost:5173
```
