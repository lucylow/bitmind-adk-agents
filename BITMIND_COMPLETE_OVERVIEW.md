## 🔧 **Customization**

### **Update Proposals**

Edit `mockProposals` in `BitMindShowcase.tsx`:

```tsx
const mockProposals = [
  {
    id: "PROP-2024-003",
    title: "Your Proposal",
    // ... rest of fields
  }
];
```

### **Modify AI Responses**

Edit `handleSendMessage` function:

```tsx
if (msg.includes('keyword')) {
  aiContent = "Your response";
}
```

### **Change Theme Colors**

```tsx
// Current: Blue & Purple
from-blue-600 to-purple-600

// Change to: Green & Teal
from-green-600 to-teal-600
```
