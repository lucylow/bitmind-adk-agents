🐛 KNOWN ISSUES & QUICK FIXES
================================================================================

Issue 1: Ethers.js Version Mismatch
------------------------------------
Problem: blockchain-client.ts uses ethers v5 syntax, package.json has v6

Fix: npm install ethers@5

Or update blockchain-client.ts to v6 syntax:
   // v5: new ethers.providers.JsonRpcProvider(url)
   // v6: new ethers.JsonRpcProvider(url)


Issue 2: Missing @iqai/adk
---------------------------
Problem: ADK-TS may not be installed/available

Fix: Create src/adk-mock.ts with mock exports (see docs)


Issue 3: Missing Dependencies
------------------------------
Fix: npm install body-parser express graphql graphql-request
     npm install --save-dev @types/express @types/jest jest ts-jest


Issue 4: Type Errors
--------------------
Fix: npm install --save-dev @types/node typescript
